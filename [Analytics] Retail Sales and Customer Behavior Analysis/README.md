# 🛍️ Retail Sales & Customer Behavior Analysis

A comprehensive Python analytics project exploring retail sales performance and customer purchasing behavior. The project identifies key sales drivers, customer segments, shopping patterns, and product performance to support data-driven business decisions.


## 📊 Key Features

- Sales performance overview
- Customer demographic analysis
- Product category performance
- Customer purchasing behavior
- Revenue and quantity analysis
- Seasonal and monthly sales trends
- Correlation analysis between business metrics

## 🧹 Data Preparation

The project analyzes retail transaction data together with customer information.

Data preprocessing included:

- Missing value treatment
- Duplicate removal
- Data type conversion
- Feature engineering
- Customer segmentation
- Sales metric calculation
- Exploratory data analysis (EDA)

The cleaned dataset was used to generate business insights and identify customer behavior patterns.

## 📁 Tools & Technologies

- **Python**
- **Pandas** – Data manipulation
- **NumPy** – Numerical analysis
- **Matplotlib** – Data visualization
- **Seaborn** – Statistical visualization
- **Scikit-learn** – Customer segmentation and analytics
- **Jupyter Notebook**

## 🧠 Additional Highlights

- End-to-end exploratory data analysis workflow
- Customer behavior and purchasing pattern analysis
- Retail KPI visualization
- Actionable business recommendations based on analytical findings
