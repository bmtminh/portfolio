# 🧠 Data Analytics Portfolio

Welcome to my personal analytics portfolio!  
This repository showcases a curated collection of data analysis and visualization projects using **Power BI**, **Python**. I've worked on in areas such as **Data Analytics**, **Business Intelligence**, with a strong focus on storytelling, business context, and visual clarity.

## 🕵️‍♀️ About my projects

Each folder in this repository represents a standalone project, featuring data processing workflows, analysis logic, business context, or even reporting/dashboard artifacts, designed to explore real-world challenges and translate raw data into actionable insights.

---

## 📁 Projects Included

### ⚡ [Electrics Retailer](./Electrics%20Retailer)
An interactive dashboard analyzing product performance, customer segments, and store-level KPIs for a global electronics retail brand.

### 👥 [HR Employees Churn](./HR%20Employees%20Churn)
A workforce analytics report investigating attrition patterns and identifying high-risk employee groups using demographic and performance data.

### 👥 [Grocery Sales](./Grocery%20Sales%20)
An exploratory data analysis project on retail grocery sales, featuring correlation tracking, profit outlier detection, and time-series performance evaluation across different product categories and regions

### 👥 [Rossmann Store](./Rossmann%20Store%20)
A time-series prediction project aiming to forecast daily store sales for Rossmann, utilizing exploratory data analysis (EDA) to understand sales distributions and the impact of store closures, and preparing the data for advanced modeling.

### 🎬 [Netflix Content Analytics](./Netflix)
A comprehensive exploratory data analysis of Netflix's movie and TV show catalog, uncovering content distribution, genre trends, release patterns, country contributions, and audience ratings through Python-based data cleaning, visualization, and statistical analysis.

### 🛍️ [Retail Sales & Customer Behavior Analysis](./Retail%20Sales%20%26%20Customer%20Behavior)
An end-to-end retail analytics project exploring customer purchasing behavior, sales performance, product preferences, and seasonal trends. The analysis provides actionable business insights through data preprocessing, exploratory analysis, customer segmentation, and interactive visualizations using Python.

### 🕸️ [E-commerce Product Data Crawling](./E-commerce%20Product%20Data%20Crawling)
A Python web scraping project that automates product data collection from Lazada and Tiki, extracting pricing, ratings, reviews, brands, and seller information to support market research and e-commerce analytics.
