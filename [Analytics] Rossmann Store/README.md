# 🏪 Rossmann Store Sales Analysis

A comprehensive data analytics project analyzing Rossmann pharmacy store sales. The project explores historical sales patterns, customer behavior, promotional campaigns, competition effects, and seasonal trends to generate actionable business insights for retail operations.

## 📊 Key Features

- Store sales performance analysis
- Promotion effectiveness evaluation
- Customer traffic analysis
- Seasonality and holiday impact
- Competition distance analysis
- Store type comparison
- Sales forecasting preparation through feature engineering

## 🧹 Data Preparation

The project combines Rossmann sales records with store information to create a unified analytical dataset.

Data preprocessing included:

- Merging sales and store datasets
- Handling missing values
- Feature engineering from date variables
- Encoding categorical features
- Cleaning competition and promotion data
- Preparing datasets for exploratory analysis and predictive modeling

The processed dataset was used to analyze factors influencing daily sales and store performance.
