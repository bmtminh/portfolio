# 🎬 Netflix Content Analytics

A Python-based exploratory data analysis (EDA) project that investigates Netflix's catalog of movies and TV shows. The analysis uncovers content distribution, genre trends, country contributions, release patterns, and audience ratings to provide valuable insights into Netflix's global content strategy.

## 📊 Key Features

- Distribution of Movies vs TV Shows
- Content growth over the years
- Top producing countries
- Most popular genres and categories
- Rating distribution across content
- Duration analysis for movies and TV shows
- Interactive visualizations for storytelling

## 🧹 Data Preparation

The analysis was conducted on the Netflix titles dataset containing metadata for movies and TV shows.

Data preprocessing included:

- Handling missing values
- Removing duplicated records
- Converting date columns into datetime format
- Standardizing categorical variables
- Feature engineering for release year, duration, and content type

The cleaned dataset was then explored using descriptive statistics and visual analytics.
