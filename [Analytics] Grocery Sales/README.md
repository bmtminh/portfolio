# 🛒 Grocery Sales Analytics

A Python-based retail analytics project that explores grocery sales performance, customer purchasing behavior, and product trends. Through exploratory data analysis (EDA), the project uncovers key business insights to support sales optimization and inventory planning.


## 📊 Key Features

- Overall sales performance analysis
- Revenue trends by month and year
- Best-selling product categories
- Regional and city-level sales comparison
- Customer segment analysis
- Shipping mode and order priority analysis
- Profitability across products and categories

## 🧹 Data Preparation

The analysis was performed on a grocery retail sales dataset containing transaction, customer, product, and shipping information.

Data preprocessing included:

- Handling missing values
- Converting date fields into datetime format
- Feature engineering (Month, Year, Quarter)
- Removing duplicated records
- Data validation and type conversion
- Preparing datasets for exploratory analysis

The cleaned dataset was then analyzed to identify sales trends, customer purchasing patterns, and business opportunities.
